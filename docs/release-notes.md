# Luno Animate — Early studio

A little less complicated. A lot more animated.

## Included
- A vector drawing canvas with pen, shape, and artwork import tools.
- A poseable character with a connected 15-bone rig and two-bone inverse kinematics.
- A keyframe timeline, automatic pose keys, easing, playback, and starter motions.
- Local autosave, undo/redo, and portable `.luno` projects.
- Animated GIF, PNG, and SVG export.
- A first-run studio setup wizard.

## Install
- **Windows:** run the `.exe` setup wizard.
- **macOS:** open the `.dmg`, then drag Luno Animate into Applications. Pick `arm64` for Apple silicon or `x64` for Intel.
- **Linux:** use the `.deb` package, or make the `.AppImage` executable and open it.

This is an early editor, not full Adobe Animate feature parity. Imported images animate as whole objects; automatic image mesh skinning, audio, video export, and multiple scenes are not included yet. GIF export supports up to 300 frames and a maximum side length of 960 px.

Builds without configured signing certificates are **unsigned** development builds. Windows can show an unknown-publisher warning; macOS builds must be signed and notarized for normal public distribution. Review the source and checksums before installing.
